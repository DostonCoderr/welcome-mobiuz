
Salom! Men "Mobiuz Welcome Book" loyihasini qilyapman. Loyiha 4 qismdan iborat:

1. **Backend API** (mobiuz-api): Node.js + Express + MongoDB (Mongoose). Lokalda http://localhost:5000 da ishlayapti. Auth (JWT) ishlaydi. Modellar: Employee, Department, Position, Section, Banner, Feedback, User, Notification. Admin login: admin@mobi.uz / admin123. Rasm yuklash (multer) ham ishlaydi.

2. **Admin Panel** (mobiuz-admin): React + Vite + Tailwind + Framer Motion. Dizayn qizil-qora, qor yog'ishi (Snowfall), animatsiyalar. Sahifalar: Login, Dashboard, Employees, Departments, Positions, Sections, Banners, Feedbacks, Notifications, Settings (profil, avatar, parol, adminlar). Tarjima tizimi (UZ/RU) `useT` hook va `dict.ts` orqali ishlaydi. Hozir lokalda ishlayapman.

3. **WebApp** (frontend): React + Vite. Vercel'da joylashgan (https://welcome-mobi.uz). Hali eski API yoki Supabase'ga ulangan bo'lishi mumkin — yangi API'ga ulash kerak.

4. **Telegram Bot** (bot): Telegraf (Node.js). Serverda (VPS) pm2 orqali ishlayapti. Hali eski API'ga ulangan — yangi API'ga ulash kerak.

**MongoDB Atlas**: cluster0.9nahxeq.mongodb.net (mobiuz_welcome bazasi). Barcha ma'lumotlar (16 xodim, 6 bo'lim, 5 lavozim, 2 maqola) ko'chirilgan.

**Hozirgi holat**:
- Node.js versiyasi nvm-windows orqali 24.19.0 ga ko'tarildi (avval 20.18.0 edi).
- Admin Panelda `dict.ts` faylida `error is not defined` xatosi chiqyapti — `t.common.error` va `t.settings.admins.error` kalitlari to'g'ri joylashtirilmagan. Bu xato butun ilovani ishlamay qo'yishiga sabab bo'lyapti (Vite "Failed to reload" xatosi).
- Admin Panelning barcha sahifalari yozilgan, lekin `dict.ts` xatosi tufayli ishga tushmayapti.

**Keyingi qadamlar**:
1. **`dict.ts` xatosini to'g'rilash** — `error` kaliti to'g'ri joylashtirilishi kerak.
2. Admin Panelni ishga tushirish (`npm run dev`).
3. API'ni serverga (VPS) deploy qilish (GitHub → clone → .env → pm2 → Nginx).
4. WebApp va Botni yangi API'ga ulash (api.ts va helpers.ts ni o'zgartirish).
5. Admin Panelni Vercel'ga deploy qilish.
6. Yakuniy test va xavfsizlik.

Menga hozir **`dict.ts` dagi `error is not defined` xatosini to'g'rilash**da yordam bering. Bu xato tufayli Admin Panel ishga tushmayapti.

`dict.ts` faylining to'liq kodini qanday to'g'rilashni ayting — `common.error` va `settings.admins.error` kalitlarini qanday joylashtirish kerak?
